# أكاديمية السند المتصل لخدمة القرآن الكريم

منصة موحدة لإدارة أكاديمية تحفيظ القرآن الكريم — مهيّأة للعمل والنشر من
**Google AI Studio**.

هذه النسخة تعمل بالكامل في المتصفح (React + Vite + TypeScript) بلا خادم خلفي،
وتستخدم **جوجل شيتس** كمخزن دائم مشترك عبر Google Apps Script.

---

## 1) التشغيل داخل Google AI Studio

1. افتح [aistudio.google.com](https://aistudio.google.com) واذهب إلى **Build**.
2. من زر **+ (Add files)** في صندوق الأوامر اختر رفع ملفات المشروع، أو استورد
   المستودع عبر **Import from GitHub** بعد رفع هذا المجلد إلى GitHub.
3. سيتعرّف AI Studio تلقائياً على `metadata.json` و `package.json` و `index.html`،
   ثم يثبّت الحزم ويشغّل المعاينة.
4. للنشر: اضغط **Deploy** لنشر التطبيق على **Cloud Run**، أو **Share** لمشاركته.

> لا يحتاج هذا المشروع إلى مفتاح Gemini للعمل. إن أردت لاحقاً إضافة ميزات ذكاء
> اصطناعي، المفتاح متاح عبر `process.env.API_KEY` وهو مُعرّف مسبقاً في
> `vite.config.ts`.

## 2) التشغيل على جهازك

```bash
npm install
npm run dev      # معاينة على http://localhost:3000
npm run build    # بناء نسخة الإنتاج في مجلد dist
npm run preview  # معاينة نسخة الإنتاج
npm run check    # فحص أنواع TypeScript
```

## 3) ربط جوجل شيتس (التخزين الدائم)

بدون هذه الخطوة تعمل المنصة بالكامل، لكن البيانات تبقى في متصفح كل مستخدم على
حدة. الربط يجعل البيانات مشتركة ودائمة.

1. أنشئ ملف **Google Sheets** جديداً باسم الأكاديمية.
2. من القائمة: **الإضافات ← Apps Script** (`Extensions → Apps Script`).
3. احذف محتوى `Code.gs` والصق الكود الكامل الموجود في تبويب **"كود السكربت"**
   داخل المنصة: `لوحة الإدارة ← الربط مع جوجل شيت ← كود السكربت`.
4. **Deploy ← New deployment ← Web app** مع الإعدادات:
   - `Execute as`: **Me**
   - `Who has access`: **Anyone** (أي شخص لديه الرابط)
5. انسخ رابط النشر (`.../exec`) والصقه في المنصة:
   `لوحة الإدارة ← الربط مع جوجل شيت ← رابط Webhook` ثم **اختبار الاتصال**.
6. اضغط **رفع نسخة كاملة إلى جوجل شيت** مرة واحدة لتهيئة المخزن.

بعد ذلك تُحفظ كل التعديلات تلقائياً، وتُحمَّل البيانات عند فتح المنصة من أي جهاز.

### كيف تُخزَّن البيانات؟

| الورقة | المحتوى |
| --- | --- |
| `_DB_SNAPSHOT` (مخفية) | المخزن الدائم الحقيقي — كل كيان في صف بصيغة JSON، مقسّم على أجزاء عند تجاوز 45,000 حرف |
| الطلاب / المعلمات / الحصص اليومية / التسجيلات / المالية / المصروفات | جداول مقروءة للبشر للتقارير والاستعراض، تُحدَّث عبر زر **مزامنة الكل** |

تعمل المنصة بشكل كامل عند انقطاع الاتصال، وتُستأنف المزامنة تلقائياً عند عودته.

## 4) حسابات الدخول التجريبية

| الدور | اسم المستخدم | كلمة المرور |
| --- | --- | --- |
| الإدارة | `admin` | `Sanad@1447` |
| المعلمات | `t1` … `t25` | `Teach@1447` |
| الطلاب | `s1` … `s8` | `Talib@1447` |
| أولياء الأمور | حسب بيانات ولي الأمر | `Parent@1447` |
| المسوّقون | حسب بيانات المسوّق | `Aff@1447` |

> **مهم قبل الاستخدام الحقيقي:** هذه كلمات مرور تجريبية مكتوبة داخل الكود
> (`src/services/auth.ts`). غيّرها قبل نشر المنصة لمستخدمين حقيقيين.

## 5) بنية المشروع

```
├── index.html            # صفحة الدخول (RTL + خطوط Tajawal و Amiri)
├── index.tsx             # نقطة التشغيل (React 19)
├── App.tsx               # الموجّه الرئيسي وحارس الصلاحيات
├── metadata.json         # تعريف التطبيق لمنصة Google AI Studio
├── package.json          # الحزم وأوامر التشغيل
├── vite.config.ts        # إعداد Vite و Tailwind والاسم المستعار @
├── tsconfig.json
└── src/
    ├── index.css                 # أنماط عامة + Tailwind 4
    ├── components/               # 22 واجهة: الموقع العام والبوابات والتقارير
    ├── services/
    │   ├── database.ts           # محرّك البيانات المحلي (localStorage)
    │   ├── cloudBridge.ts        # جسر التخزين الدائم مع جوجل شيتس
    │   ├── googleSheetsSync.ts   # كود Apps Script ودوال المزامنة
    │   ├── auth.ts               # الدخول والصلاحيات
    │   ├── quranData.ts          # بيانات السور والأجزاء
    │   ├── curriculumData.ts     # المناهج والخطط
    │   ├── evaluations.ts        # معادلات التقييم والدرجات
    │   ├── placement.ts          # اختبار تحديد المستوى
    │   ├── reportsAnalyticsService.ts
    │   ├── notificationService.ts
    │   ├── comprehensiveDemoData.ts
    │   └── testSuite.ts          # فحص ذاتي للمنصة من لوحة الإدارة
    ├── types/
    └── utils/
```

## 6) ما الذي تغيّر عن النسخة السابقة

| أُزيل | البديل |
| --- | --- |
| خادم Express + tRPC + MySQL/Drizzle | لا خادم — التطبيق يعمل في المتصفح |
| مجلدات `server/` و `shared/` و `drizzle/` | — |
| إضافات Vite الخاصة بمنصة الاستضافة السابقة | إعداد Vite قياسي |
| تسجيل الدخول عبر OAuth الخاص بالمنصة السابقة | نظام الدخول الداخلي في `auth.ts` |
| حفظ اللقطة عبر `trpc.academy.save` | `src/services/cloudBridge.ts` عبر جوجل شيتس |
| مكتبة shadcn/ui ونماذج العرض غير المستخدمة | حُذفت — الواجهات تستخدم Tailwind مباشرة |

الحزم انخفضت من أكثر من 70 حزمة إلى 4 حزم تشغيل فقط:
`react`, `react-dom`, `lucide-react`, `qrcode`.
